参考世界

在 7 个内置的光线投射小世界里录制 32 段操作，故意混入挂机、300 ms 错位和时钟漂移各一段，再筛选、构建训练集，并导出具身格式（LeRobot 形状）。不用下载，几分钟跑完。

完成后：30/32 通过，错位那段显示 realigned +300 ms。

4D 世界

把管线里的精确几何变成 3D 高斯（3DGS）随时间变化的世界，在浏览器里播放、环绕、编辑。机器人场景从任务描述直接生成，按真实的盒子和球体表面采样；游戏世界用引擎的深度和玩家位姿逐帧抬升。不在本机跑任何模型。

从任务描述生成

任务 → 场景 → 通过保真度闸门的回合 → 3D 高斯。桌面、盒子是静态层；方块和夹爪每帧移动。

从游戏世界生成

在内置光线投射世界里录一段，再用引擎深度和玩家位姿抬升：墙和地面合并为静态层，敌人、道具逐帧出现。
